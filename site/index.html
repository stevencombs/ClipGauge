Ready for script writing

Hand the transcript bundle to your favorite chat bot. Every line is time-stamped and points back to its clip, so the bot can cite b-roll and quotes.

▶

Multi-project queue

Reorder, pause, skip or remove projects. Each one has its own mode, Transcribe switch, progress and undo.

↻

Resumes where it stopped

Stopped, quit, crashed or the Mac went to sleep? Resume picks up with the next unfinished clip.

◎

Sees and listens

Ollama's qwen2.5vl looks at 9 frames of each clip; whisper.cpp writes down what's said.

▣

Photos too

JPEG, HEIC, DNG, PNG and more, dated from the camera's own EXIF time.

✦

Ask the model, right in the first window

The chat sits at the top of the menu bar popover and beside the queue in the main window. Pick a model, attach a clip's transcript, press ⇧⌘A to jump in. The model stays loaded while ClipGauge is open and is unloaded when you quit. It pauses while clips process.

⚙

Choose the vision and speech models in Settings, or leave it on Automatic for your Mac's memory.

⇄

Synced preferences

Point it at a folder your Macs already sync. Only preferences go there, never clips, notes or transcripts.

Safety

Careful with your footage.

ClipGauge was built for a real editing drive, so the rules are strict.

The rules, in plain words

  • Never overwrites. A name that's taken gets _t02, _t03 and so on.
  • Keeps original dates. Created and modified dates survive every rename, move, copy and undo.
  • Everything is undoable. Every rename is logged. Undo one clip, a batch or a whole project.
  • Waits for DaVinci Resolve. It won't start while Resolve is open and pauses before the next project if it opens.
  • Dry run first. New projects start in preview mode, so you see every proposed name before anything changes.
  • Hands off. Resolve's own folders, Cloud-synced projects and folders you put on hold are refused.
  • Local only. No clip, frame, audio or transcript leaves your Mac. The models run on it.
  • No analytics, no telemetry, no account. Open source, so you can read every line.

How it works

Set it up once. Then just drop folders.

ClipGauge keeps its project folder, AI models and logs together on any internal, external or network drive you choose.

  1. 1

    Install & Setup

    Open the app and Setup checks Homebrew, Python, ffmpeg, Ollama and whisper.cpp. Install Missing… asks before every install.

  2. 2

    Drop your folders

    Drag folders or clips onto the window or the menu bar icon. Rename them in place, or copy them into the inbox first.

  3. 3

    Start the queue

    Run a dry run to preview, then go live. When each project finishes, its transcript bundle lands next to the clips.

Install

Up and running in an evening.

Most of the time is the one-time model download (about 6 GB).

Recommended

Homebrew or GitHub Releases

With Homebrew, one command installs ClipGauge plus ffmpeg, Ollama and whisper.cpp. The AI models are still pulled in Setup, only after you approve.

brew install --cask stevencombs/tap/clipgauge

Or download ClipGauge-0.8.5.zip, unzip it and drag ClipGauge.app into Applications. Each release has a .sha256 file so you can check the download.

shasum -a 256 -c ClipGauge-0.8.5.zip.sha256

Requirements

What you need

  • macOS 14 Sonoma or later; Apple silicon recommended (Intel works, but slowly)
  • 16 GB of memory or more
  • About 10 GB free for the AI models, plus room for clips
  • Homebrew, Python 3.10+, ffmpeg, Ollama and whisper.cpp (Setup installs them with your OK)
  • Optional: DaVinci Resolve. ClipGauge simply waits while it's open
Storage

Any drive works

Put the project folder on your Mac's internal disk, an external SSD, or a network share. A fast SSD is quickest, and an external one lets you move it between Macs without re-downloading models.

FAQ

Questions, answered.

Does anything get uploaded?

No. The vision model runs in Ollama on your Mac and the speech model runs in whisper.cpp on your Mac. The network is only used to download the tools and models during setup, and for an optional update check.

What if it gets a name wrong?

Clips it isn't sure about keep their original name and are flagged needs review. You can accept the proposal or type your own. Any rename can be undone, by clip, batch or project, and the files keep their original dates.

Why does macOS warn me the first time?

Releases aren't notarized by Apple yet, so a downloaded copy gets a Gatekeeper warning. (The Homebrew cask clears the download quarantine flag on ClipGauge.app only, so it opens normally.) Right-click ClipGauge.app, choose Open, then Open again, or use System Settings › Privacy & Security › Open Anyway.

Do I need a particular drive?

No. Any internal, external or network drive works (APFS, exFAT or HFS+). Network drives are slower and must stay mounted during a run.

How fast is it?

On a 16 GB MacBook Air, plan on a few minutes per clip with the default model. Queue a batch before bed and it keeps the Mac awake until it's done.

Does it work with DaVinci Resolve projects?

Yes, carefully. It won't run while Resolve is open, never touches Resolve's own folders or Cloud-synced projects, and asks once before renaming clips inside your Resolve folder, because Resolve will need to relink them.

What does it cost?

Nothing. ClipGauge is free and MIT licensed. If it saves you an evening of renaming clips, a tip is always appreciated.
